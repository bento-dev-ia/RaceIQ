### Features
- Bento Racing: the app is rebranded (window title, sidebar, messages, installer display name) as a fork of RaceIQ; Settings → About shows the AGPL-3.0 notice and source link. Install and data folders keep their old names so existing data carries over.
- Trail-braking trainer (sidebar → Treino de trail braking): top-down corner drills (hairpin, medium, fast) with a friction-circle car model where braking into the turn adds front grip. Wheel and pedals through the browser with a one-time calibration (axes and shift paddles), steering sensitivity, a 6-speed sequential gearbox with over-rev protection (or automatic), full screen, instant retry with Space/Enter or any wheel button, a 0–100 score split into brake application, trail, smoothness, grip use, gears and result, and charts of your brake, steering and gear against the ideal.
- Race engineer natural voice: paste an ElevenLabs API key in Settings → Sound; phrases are generated once, cached on disk and pre-generated for the corners ahead, then played through gain + compression (volume up to 300%) with radio pips. Without a key the browser voice is used.
- Race engineer track knowledge for Monza and Spa (marker boards, gears, turn-in references and key tips from published GT3 guides) used before you have a reference of your own, once per session as a tip, and as the visual cue when your turn-in is off. New steering diagnosis: too much / too little lock.
- "Open in-game overlay" in the sidebar and in Settings → Sound starts (or restarts) the overlay; the overlay now shows tyre core temperatures, pressures and brake temperatures with ACC windows, and a fixed brake marker plus the countdown for the next corner.
- Turn on a voice race engineer for Assetto Corsa Competizione (Settings → Sound, the sidebar button or Ctrl+Shift+E). While you drive it speaks short Brazilian Portuguese callouts: before your 2–3 costliest corners it gives the gear, the brake point in metres before turn-in and one fix (brake later/earlier, harder, trail-brake, carry more speed, earlier throttle); after a corner it says how much time you won or lost and why; at the line it gives the lap time against your previous best. The reference is your best pass through each corner, and it can also learn from AI cars on track, using their speed and brake points where they are faster. It stays silent from 150 m before each brake point until you are back on throttle. Replay a recording with `bun apps/backend/scripts/race-engineer/replay-acc.ts <recording or lap chunks…> [--bots] [--save]`.
- The race engineer now briefs every corner (gear, minimum speed, brake point) and gives a tip before every corner where you lose time, including turning in too early or too late; after a corner it names up to two causes. Callouts open and close with a team-radio pip, speak faster, and Settings suggests Microsoft Edge when the browser has no natural Portuguese voice. Its reference laps are kept per car and track in `race-engineer/` under the data folder, measured by track position, so the reference survives restarts and is no longer polluted by session laps with a wrong integrated distance.
- In-game input overlay for ACC (`bun run overlay`): a small transparent, click-through box over the game with the next corner's gear, target speed, distance to the brake point, brake % and trail-braking cue, plus a scrolling graph of throttle, brake and steering against the ideal (also drawn ahead of the car). Drag it anywhere while the game is paused or in menus; its size is set in Settings → Sound. It runs inside Bun itself (no new executable) and needs ACC in borderless window mode.
- Run RaceIQ in the native macOS app with existing lap data and saved network access; control login startup and whether closing the window quits the app.
- Choose DeepSeek for analysis, chat, auto-tune and driver profiles with its own API key. The model picker reads the models available to that key instead of using a fixed list, preselects `deepseek-flash`, keeps tool calls working, and only offers image attachments on models that accept them.

### Fixes
- Fork hardening against antivirus trojan heuristics on Windows: the installer no longer forces start-with-Windows (now an unchecked option), no longer uses a hidden VBS launcher or hidden PowerShell, and launches the app only once; the server never kills other programs listening on its port (it reuses a running RaceIQ or refuses to start); the tray icon (a hidden shell script in %TEMP%) is removed; in-app updates no longer download and silently run installers. The app no longer spawns any background child process on Windows: game detection uses an in-process Toolhelp32 snapshot (main thread only) instead of polling `tasklist` every second in every worker, API keys are encrypted with DPAPI in `%APPDATA%/RaceIQ/secrets.dpapi.json` instead of a hidden PowerShell credential script, the start-with-Windows toggle uses the registry API, the browser opens through ShellExecute, and the Diagnostics page no longer runs a burst of hardware-probing PowerShell commands. The console window stays visible; close it (or Start menu → "Encerrar RaceIQ") to stop the app. API keys saved in the Windows Credential Manager by older builds must be entered again.
- Preserve Automobilista 2 parser state when splitting recorded sessions into laps, allowing seeded sessions to migrate and replay correctly.
